# Systematic Review Evidence Workflow

## Classification
**Research-support / methodology demonstration**

## Workflow
1. Identify records.
2. Remove duplicates.
3. Screen titles and abstracts.
4. Retrieve full texts.
5. Record full-text availability.
6. Apply eligibility criteria.
7. Document exclusions.
8. Report included studies.

## Evidence
See `notebooks/25_prisma_screening_workflow.ipynb` for a synthetic screening workflow with explicit counts and a visual screening summary.

This complements the professional systematic-review case study already documented in this repository.

> Synthetic records are used for the reproducible demonstration. Actual research records are not published.
