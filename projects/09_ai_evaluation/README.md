# AI Model Evaluation — Evidence Case Study

## Classification
**Portfolio / AI services demonstration**

## Objective
Demonstrate a structured approach for evaluating AI-generated responses against explicit quality criteria.

## Evaluation dimensions
- Relevance
- Factuality
- Instruction following
- Completeness
- Clarity
- Consistency
- Safety/appropriateness where applicable

## Method
1. Define the evaluation rubric.
2. Score each response independently.
3. Record rationale.
4. Compare evaluator decisions.
5. Investigate disagreements.
6. Produce aggregate metrics.
7. Identify recurring failure patterns.
