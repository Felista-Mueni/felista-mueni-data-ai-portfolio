# Tableau Business Dashboard — Evidence Framework

**Portfolio / Business Intelligence**

## Objective
Demonstrate interactive visual analytics using a retail-style dataset.

## Views
Executive KPI view, revenue trend, regional performance, product/category analysis, customer segmentation and profitability.

## Capabilities
Calculated fields, parameters, filters, dashboard actions, tooltips and trend analysis.

## Evidence standard
The final portfolio should include screenshots or a public workbook where permitted.

> Synthetic data should be clearly identified and confidential client work should not be published.
