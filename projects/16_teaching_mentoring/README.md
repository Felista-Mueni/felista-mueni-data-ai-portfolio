# Data Science Teaching & Technical Mentoring

**Teaching / mentoring evidence**

Demonstrate the ability to translate technical data-science concepts into practical, structured learning activities.

## Topics taught
- Python fundamentals
- NumPy and pandas

- Statistics
- Data visualization
- Excel analytics
- Power BI
- Tableau
