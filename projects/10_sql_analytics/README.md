# SQL Business Analytics — Evidence Case Study

## Classification
**Portfolio / Data Analytics demonstration**

## Objective
Demonstrate practical SQL analysis for a retail-style business dataset.

## Techniques
- Relational joins
- Aggregation
- Common Table Expressions (CTEs)
- Window functions
- Ranking
- Regional revenue analysis
- Customer-level performance

## Evidence
See `notebooks/21_sql_business_case.ipynb`, which creates a reproducible SQLite database and executes business queries.

> The database is synthetic and contains no client information.
